# @mizunashi/schema

データ定義の**唯一の情報源**です。非公開パッケージ。

Zod スキーマとそこから導出した型を提供します。取得したデータの形、API レスポンスの形、パースの診断コードがすべてここに集まります。

## 構成

| ファイル | 内容 |
| --- | --- |
| `primitives.ts` | `TimeStr` / `DateStr` / 分単位の時刻変換 |
| `schedule.ts` | `Session` / `DaySchedule` / `YearSchedule` など保存するデータ |
| `response.ts` | API レスポンスの契約 |
| `diagnostics.ts` | パース時の警告・エラーコード |

## 設計上の要点

**時刻は `"HH:mm"` の文字列、分解能は分。** 現行データは毎正時のみですが、Excel の時刻小数はもともと分を表現できるため、30 分刻みになっても実装変更が要りません。

**セッションは `index` と `minutes` を持ちます。** 1 日に複数回あるのが常態なので、「その日の何回目か」を保持します。区間は `[start, end)` として扱います（終了時刻ちょうどは入浴不可）。

**`YearSchedule` は通年を前提にしません。** `coverage` を実データから算出し、`complete` で通年かどうかを持ちます。2020 年版は 4〜12 月の 275 日しかなく、会計年度のファイルも存在したためです。

**`sources` は配列です。** 会計年度ファイルを暦年に分割してマージすると、1 つの暦年が複数の原本に由来しうるためです。

## 公開型との関係

`response.ts` の定義は [`@mizunashi/api-types`](../api-types) が公開する型と**型等価であることがコンパイル時に検証されています**（`packages/api-types/test/contract.test.ts`）。

片方だけを変更すると `pnpm typecheck` が落ちます。落ちたら両方を揃えてください。アサーションを消して黙らせないでください。
