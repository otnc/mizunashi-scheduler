# @mizunashi/web

利用者向けの静的サイトです。Astro で構築し、インタラクティブな部分だけを React アイランドにしています。

## 画面構成

```
StatusHero                いま入れるか / いつまで / 次はいつから
[今日・明日] [週間] [月間]  ← 既定は今日・明日
```

| タブ | 内容 |
| --- | --- |
| 今日・明日 | 2 枚のカード。全セッションを番号付きで列挙 |
| 週間 | 今日から 7 日間。前後移動あり |
| 月間 | 月グリッド。年月送りあり |

## データの取り方

**年次データを起動時に一度だけ取得し、以降の計算はすべてクライアント側で行います。** タブ切替・週送り・月送りでネットワークアクセスは発生しません。

判定には API と同じ `computeStatus`（[`@mizunashi/core/status`](../../packages/core)）を使うので、**サーバとクライアントで結果がずれません**。API の `/status` は外部利用者向けの提供と位置づけています。

30 秒ごとに再計算します。1 秒ごとにすると読み上げが洪水になるためです。タブが非表示のときは再計算しません。

## 表示上の決めごと

**1 日に複数回入れるのが常態です。** 以下は誤りになるので実装しないでください。

| してはいけない | 正しい |
| --- | --- |
| `sessions[0]` だけ表示する | 全件を番号付きで列挙する |
| `firstStart`〜`lastEnd` を「入浴可能時間」として出す | セッションごとに出し、合計は `totalMinutes` を使う |
| 「入浴不可」＝「今日はもう無理」と書く | `nextToday` の有無で分岐する |
| 月間セルに時刻文字列を詰める | ミニタイムラインで示し、正確な時刻は詳細で見せる |

**タイムラインは 1440 分割グリッドの同一行に全セッションを載せます。** 回数が増えても高さが変わらないので、今日のカードでも週の行でも月のセルでも同じ部品が使えます。

**状態は色だけで示しません。** アイコンと文言を必ず併記します。カウントダウンは `aria-live="polite"` です。

**外部リンクは必ず [`ExternalLink.astro`](src/components/astro/ExternalLink.astro) を通します。** 直接 `<a href="https://...">` と書くと `target` と `rel` の付け忘れが起きます。`target="_blank"` に `rel="noopener"` を付け忘れると、遷移先から `window.opener` 経由でこちらのタブを操作されえます。別タブで開くことは `↗` と読み上げ用テキストの両方で伝えます。この規約は `pnpm check:invariants` で強制しています。

地図は Google マップの埋め込みです。`loading="lazy"` を付けているので、スクロールして近づくまで読み込まれません。

## ローカル開発

```bash
pnpm --filter @mizunashi/web dev
pnpm --filter @mizunashi/web build
pnpm --filter @mizunashi/web typecheck   # astro check
```

API は同一オリジンを前提にしています。別オリジンの API を叩く場合は環境変数 `PUBLIC_API_BASE` を設定してください。

## PWA / オフライン

インストール可能で、オフラインでも動きます。キャッシュするのはアプリシェルと年間データ（`/api/v1/years`、`/api/v1/years/{year}?at=none`）だけです。

**オフラインでも判定は正しく出ます。** このサイトは年間データを取得したあと端末側で `computeStatus` を実行するので、キャッシュしているのは「入れるかどうかの答え」ではなく「時間表そのもの」だからです。現在時刻に依存する API はキャッシュしません。オフライン時はその旨を表示しますが、機能は止めません。

Service Worker は [`public/sw.js`](public/sw.js) です。ビルド時のプリキャッシュ一覧は作りません。生成物名に内容ハッシュが付くため、実行時にキャッシュするだけで取り違えが起きないためです。

アイコンは `pnpm gen:icons`（[`scripts/gen-icons.mjs`](../../scripts/gen-icons.mjs)）で生成し、`public/` にコミットしています。図形と色の定義はスクリプト内の 1 か所にあり、SVG と PNG はそこから出力されます。色は `global.css` の oklch 値を sRGB に変換したものです。

## 作らないもの

| | 理由 |
| --- | --- |
| 英語版（`/en/`） | スコープ外。API は `lang` を受けるのでクライアント側で対応できる |
| `.ics` の購読ボタン | スコープ外。フィード自体は `/api/v1/calendar.ics` で提供している |
| プッシュ通知 | スコープ外。ユーザー登録も行わない |

日ごとの詳細ダイアログは未実装です。
